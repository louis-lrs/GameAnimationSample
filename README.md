# GameAnimationSample

Unreal Engine 5.5 Game Animation Sample Project

## Description

This is a sample project demonstrating game animation features in Unreal Engine 5.5, including motion matching, character movement, and animation systems.

## Requirements

- Unreal Engine 5.5
- Visual Studio 2019 or later (for C++ development)
- Windows 10/11

## Project Structure

- `Source/` - C++ source code
- `Content/` - Unreal Engine assets (blueprints, animations, materials, etc.)
- `Config/` - Project configuration files

## Getting Started

1. Open `GameAnimationSample.uproject` with Unreal Engine 5.5
2. The project will automatically compile C++ code if needed
3. Press Play to run the game

## Features

- Character movement system
- Motion matching animation system
- Animation warping
- Pose search functionality
- MetaHuman integration

## Plugins Used

- AnimationWarping
- PoseSearch
- AnimationLocomotionLibrary
- MotionWarping
- HairStrands
- Chooser
- RigLogic
- LiveLink
